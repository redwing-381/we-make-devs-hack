## QX · `service_neighbors` — Service neighbours

What a service calls directly, and who calls it directly. Returns the edges as paths so the UI can draw them and show p99 latency on each call.

```cypher
MATCH (s:Service {name: $svc})
OPTIONAL MATCH out = (s)-[:CALLS]->(:Service)
OPTIONAL MATCH inn = (:Service)-[:CALLS]->(s)
RETURN s, collect(DISTINCT out) AS calls, collect(DISTINCT inn) AS called_by
```

Example params: `{"svc": "checkout"}`
